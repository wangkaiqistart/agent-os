# Feature Specification: Tool 能力补齐与插件接入

**Feature Branch**: `specs/005-expand-tool-capabilities`

**Created**: 2026-11-18

**Status**: Draft

**Input**: User description: "实现上面的 P1、P2、全程；记忆、通知暂时不做。对照 http://localhost:4321/projects/agent-os/tool/ 补齐其他 Tool 能力。"

## 范围与边界

本功能承接 004 已交付的工具授权、统一执行、审计、脱敏、限次和截止时间底座，让 Agent 作者能够使用文件、命令、外部工具服务、提交请求、搜索和人机交互完成真实任务，并让运维人员查清当前有哪些工具及其可用状态。

本次新增 10 个工具：`read_file`、`write_file`、`list_dir`、`shell`、`http_post`、`edit_file`、`grep`、`glob`、`ask_user`、`web_search`。同时交付 Java 插件接入、MCP 客户端与生命周期、文件/命令授权、命令行与只读服务工具查询，以及贯穿所有能力的验收证据。既有 `http_get` 继续保留。

“全程”表示所有上述能力都需要正常、拒绝、失败、超时、取消和审计闭环的验证。P1 为插件、基础文件、Shell 和 MCP；P2 为其他工具与查询入口。

明确排除 `save_memory`、`recall_memory`、`notify`、通知渠道管理、长期记忆及通知服务；不新增定时调度、完整会话服务或管理界面。不实现复杂的允许/拒绝策略引擎、工具搜索与渐进暴露、同一响应内并行执行工具、容器或虚拟机隔离、AgentOS 对外提供 MCP 服务、多租户隔离。`web_search` 搜索互联网信息，和延期的“搜索工具目录”是两种能力。

本期文件与命令能力服务于可信单机部署。白名单限制直接请求的目标，不声明可以隔离已获准程序内部的文件或网络行为；外部 MCP 服务的内部动作由其自身权限边界负责。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 接入企业自定义工具 (Priority: P1)

业务开发者添加一个 Java 工具后，Agent 作者能通过声明工具名使用它，无需改动 Agent 的思考循环。运维人员能定位定义错误和重名冲突。

**Why this priority**: 后续所有工具都需要相同的注册、授权和治理路径，插件接入也决定企业能否独立扩展业务能力。

**Independent Test**: 增加一个查询类插件和一个带副作用的插件，分别演示授权执行、未授权零执行、重名失败及执行前审计失败零执行。

**Acceptance Scenarios**:

1. **Given** 部署中加入合法的 Java 工具定义或显式工具回调，**When** 系统加载工具，**Then** 它能进入工具目录，声明该工具的 Agent 可以使用，未声明的 Agent 不可见也不能执行。
2. **Given** 插件缺少名称、描述或有效输入约束，或与其他来源发生名称冲突，**When** 建立或更新目录，**Then** 对应注册被拒绝，报告安全的来源与名称，既有工具不被静默替换。
3. **Given** 插件声明了超时、结果长度及幂等属性，**When** 执行工具，**Then** 声明生效且仍受本轮上限约束；未声明幂等性的插件默认不自动重试。
4. **Given** 插件已注册，**When** 审计写入失败或执行授权失效，**Then** 插件真实执行次数为零，且没有绕过治理的备用执行路径。

---

### User Story 2 - 在授权目录内读写文件 (Priority: P1)

Agent 作者让 Agent 读取任务资料、列出目录或保存产物；运维人员限制允许访问的位置，并能区分读取和写入授权。

**Why this priority**: 文件工具是读取参考资料和保存结果的基础，也为后续文件编辑与搜索提供一致的边界。

**Independent Test**: 使用独立临时工作区演示读、写、目录列表及越界拒绝，核对文件实际内容、修改前后状态和审计。

**Acceptance Scenarios**:

1. **Given** 文件位于允许读取的目录，**When** 调用 `read_file`，**Then** 返回受限文本；调用 `list_dir` 时返回有序、受条数限制的直接子项。
2. **Given** 目标处于允许写入的目录且父目录存在，**When** 调用 `write_file` 创建文件，**Then** 完成后可读回同一内容；目标已存在但未明确允许覆盖时失败，原内容不变。
3. **Given** 请求通过上级目录、绝对路径、软链接或相似目录名前缀访问未授权位置，**When** 读取、列目录或写入，**Then** 在实际动作前被拒绝，目录外内容不被读出或修改。
4. **Given** 文件过大、编码不受支持、目标不是普通文件，或写入前授权目标发生变化，**When** 操作执行，**Then** 返回明确安全错误；在写入提交前失败时不得留下半个目标文件或破坏原文件。
5. **Given** Agent 通过软链接读取参考资料，**When** 最终目标也在读取授权范围内，**Then** 可以读取；最终目标越界时拒绝，不因软链接本身获得额外权限。

### User Story 3 - 执行明确授权的本地命令 (Priority: P1)

运维人员授权指定可执行文件及工作目录，Agent 用独立参数执行任务，并在结束或取消后得到受限结果。

**Why this priority**: 本地命令能复用已有脚本和工具，但必须先固定启动权限与进程清理边界。

**Independent Test**: 使用无外部副作用的本地命令替身验证参数原样传递、退出码、输出截断、拒绝零启动及超时后的进程清理。

**Acceptance Scenarios**:

1. **Given** 可执行文件与工作目录均已授权，**When** 调用 `shell`，**Then** 参数作为独立值传递，返回退出码和受限输出。
2. **Given** 参数包含管道、重定向或命令替换样式字符，**When** 执行，**Then** 这些字符只作为参数，不触发额外命令或解释器。
3. **Given** 可执行文件未授权、工作目录越界或预算已失效，**When** 尝试执行，**Then** 不启动进程。
4. **Given** 命令持续输出、等待或产生子进程，**When** 超时、取消或租约失效，**Then** 停止等待并清理本次启动且仍可识别的进程及子进程，不再启动后续动作，也不自动重跑。

---

### User Story 4 - 接入和维护外部 MCP 工具 (Priority: P1)

Agent 作者引用部署者配置的 MCP 服务，使用远程工具；单个服务失联时，其他工具和本地应用仍能使用。

**Why this priority**: 复用现成或自建的 MCP 服务是接入企业外部能力的主要路径，需要连通性、授权和故障隔离共同成立。

**Independent Test**: 使用受控服务替身分别演示本地进程和远程连接、工具发现与调用、双服务同名工具、失联恢复及应用关闭。

**Acceptance Scenarios**:

1. **Given** 配置了可用服务，**When** 系统发现其工具，**Then** 工具带有可辨识来源，与本地工具经过同一授权和审计路径；只有声明该服务及对应工具名的 Agent 可见。
2. **Given** 两个服务提供同名工具，**When** 注册，**Then** 两者具有稳定且可区分的公开名称；仍有冲突时拒绝冲突项，不覆盖本地工具。
3. **Given** 某服务无法连接或初始化超时，**When** 应用启动或 Agent 加载，**Then** 本地能力及其他服务可用，查询中能看到该来源不可用；引用该已配置来源的 Agent 不因暂时失联而无法加载。
4. **Given** 来源不可用，**When** 模型仍请求其工具，**Then** 得到可继续的安全不可用结果，真实远程动作次数为零，不能回退到同名本地能力。
5. **Given** 服务恢复且工具清单变化，**When** 后续轮次开始，**Then** 使用通过校验的新清单；恢复不得扩大 Agent 授权，当前轮次的名称和来源关联不被替换。
6. **Given** 外部服务记录收到的参数与元数据，**When** 调用其工具，**Then** 必要业务参数可收到，AgentOS 内部租约、轮次对象、工作区上下文和未明确允许的元数据均未发送。
7. **Given** 应用关闭或某次远程调用超时，**When** 清理连接和本地启动的服务进程，**Then** 在受限时间内完成，不重复执行完成状态不明的调用。

---

### User Story 5 - 向授权地址提交数据 (Priority: P2)

Agent 通过 `http_post` 向获准的外部服务提交文本或结构化数据，用户能知道请求是否成功或结果是否不确定。

**Why this priority**: 读取之外的系统集成需要提交能力，且提交可能产生副作用，必须避免隐含重放。

**Independent Test**: 使用本地接收服务验证提交内容、实际请求数、白名单拒绝、跳转拒绝、超限和已提交后超时的行为。

**Acceptance Scenarios**:

1. **Given** 目标地址已授权且请求处于大小限制内，**When** 提交数据，**Then** 服务收到一次与约定一致的正文和内容类型，返回结果经脱敏和长度限制。
2. **Given** 初始地址非法、未授权或请求正文超限，**When** 请求工具，**Then** 目标服务收到零请求。
3. **Given** 服务返回跳转，**When** 工具处理响应，**Then** 返回安全的不支持跳转结果，不向下一跳重发正文。
4. **Given** 请求已提交但响应超时、连接中断或完成审计未确认，**When** 本轮结束，**Then** 不自动重发，并区分“可能已执行”与确定未发送；超大或非成功响应不回显正文。

---

### User Story 6 - 精确编辑和搜索工作区文件 (Priority: P2)

Agent 在授权目录内查找文件和文本，并只在明确匹配时替换指定内容，避免误改。

**Why this priority**: 精确修改与受限搜索能减少整文件覆盖和反复读取的成本。

**Independent Test**: 用含重复文本、空文件、二进制文件和越界软链接的临时目录验证匹配、条数上限、跳过原因和修改前后内容。

**Acceptance Scenarios**:

1. **Given** 旧文本在目标文件中恰好出现一次，**When** 调用 `edit_file`，**Then** 只替换这一处，其他内容不变；旧文本为空、不存在或出现多次时失败，原文件不变。
2. **Given** 搜索范围已授权，**When** 调用 `grep` 或 `glob`，**Then** 返回有序、受限的文本匹配位置或文件路径，超出结果或扫描预算时明确标记截断。
3. **Given** 搜索遇到二进制、非 UTF-8、过大文件或无权读取的文件，**When** 继续搜索，**Then** 不读出越界内容，按安全原因计数跳过，不因单个文件失败中断全部结果，也不把不完整扫描报告成完整无匹配。
4. **Given** 编辑期间目标发生变化，**When** 准备提交替换，**Then** 安全失败，不能静默覆盖期间产生的新内容。

---

### User Story 7 - 在支持交互的入口询问用户 (Priority: P2)

Agent 需要补充信息时向当前用户提问，其他入口不会因没有可回答问题的人而无限挂起。

**Why this priority**: 明确交互能力边界可以让同一 Agent 在命令行和无人值守环境中得到可预测结果。

**Independent Test**: 使用可交互输入和无人值守输入替身验证提问、回答、结束输入、取消和超时，不依赖人工一直守候。

**Acceptance Scenarios**:

1. **Given** 当前入口支持交互，**When** 调用 `ask_user`，**Then** 向该入口展示问题并把本次回答交回原调用，不与其他轮次串用输入。
2. **Given** 当前入口是无人值守或不支持交互，**When** 请求提问，**Then** 立即返回明确的安全不支持结果，不等待本地控制台。
3. **Given** 输入结束、回答超限或本轮被取消，**When** 等待回答，**Then** 按确定规则返回错误或结束等待，不自动重复提问，不再接收迟到回答作为本轮结果。

---

### User Story 8 - 搜索外部信息 (Priority: P2)

Agent 通过配置的搜索服务获得标题、链接和摘要，再决定是否读取来源，用户能区分没有结果和搜索服务失败。

**Why this priority**: 搜索能提供信息发现能力，但不能绕过既有网络授权和结果治理。

**Independent Test**: 配置一个搜索实现，以本地替身验证有结果、空结果、服务失败、地址拒绝及敏感信息清理；单独记录真实服务可用性。

**Acceptance Scenarios**:

1. **Given** 搜索服务已配置且获准访问，**When** 调用 `web_search`，**Then** 返回受条数和长度限制的标题、链接、摘要，不自动访问每条结果链接。
2. **Given** 服务未配置、地址未授权或查询超限，**When** 调用，**Then** 给出可区分的安全错误，前置拒绝时服务请求数为零。
3. **Given** 服务返回空结果、错误、超大响应或迟到结果，**When** 工具处理，**Then** 分别表示完整空结果、安全失败或截断，不伪造搜索成功，不泄漏凭证或无限等待。

---

### User Story 9 - 查看工具目录及可用状态 (Priority: P2)

运维人员在命令行或只读服务入口查看工具名称、说明、来源与状态，并查看指定 Agent 实际可用的集合。

**Why this priority**: 工具来源增多之后，需要直接定位“未注册、未授权、服务不可用”的差异，减少试错调用。

**Independent Test**: 对同一目录分别执行命令行和服务查询，比较全局目录、指定 Agent 的授权集合与不可用来源，检查查询没有产生模型或工具调用。

**Acceptance Scenarios**:

1. **Given** 目录含本地和远程工具，**When** 查询工具，**Then** 两个入口均能展示名称、描述、来源、可用状态；不可用服务即使尚未发现工具，也有来源级状态记录。
2. **Given** 指定 Agent，**When** 查询其工具集合，**Then** 返回与该 Agent 运行时相同的授权集合及不可用原因，未授权工具不会被当作可用工具。
3. **Given** 配置中含凭证、远程连接地址或本地启动环境，**When** 查询，**Then** 不泄露凭证、含密钥的地址、环境值和内部上下文；查询不启动模型、不执行工具，也不为查询创建会话或轮次。
4. **Given** 查询服务入口可用，**When** 只使用工具查询，**Then** 不要求完整会话、通知或记忆服务已经实现。

### Edge Cases

- 读写路径为空、含上级目录、通过软链接指向越界位置，或文件授权范围仅为同名前缀目录。
- 新文件的父目录是软链接、目标在校验后被替换，或写入/编辑提交之前发生故障。
- 文件大于限制、非 UTF-8、二进制、设备文件、权限不足；搜索扫描部分失败且没有命中。
- 直接命令路径、软链接后的真实程序与白名单不符，或工作目录被替换；解释器获准不等于脚本被隔离。
- 命令不断输出、拒绝正常退出或启动子进程；截止时间到达后不得继续占用等待路径。
- 同一插件重复发现、插件与远程工具同名、同名服务重复配置，或远程服务恢复时工具名称变化。
- 远程服务尚未完成发现时无法确认具体工具名；已知不可用来源的延期校验不得变成对任意未知名称的放行。
- MCP 的传输连接、发现、调用、重连各阶段失败；当前轮次持有的旧工具不得被静默改指向新来源。
- POST 已在服务端生效但客户端没有收到响应；跳转不能触发敏感正文重放。
- 用户输入结束、两个轮次同时尝试交互、非交互入口误调用，以及取消后的迟到回答。
- 搜索无匹配、扫描达到上限和服务故障是三种不同结果；搜索返回的链接不构成访问授权。
- 工具在副作用完成后遇到审计故障或租约丢失；不能把实际动作报告成“确定没有执行”。
- 本期已排除的记忆或通知工具名被声明时，仍按未知工具处理，不新增占位的成功实现。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在保留既有 `http_get` 的基础上交付范围中列出的全部 10 个工具，并分别提供可演示的独立使用路径；不得把仅有声明、未注册或未通过行为验收的工具称为可用。
- **FR-002**: 系统 MUST 将内置工具、Java 插件及 MCP 工具纳入同一工具目录与统一受治理执行链；接入新插件不得要求复制或修改思考循环的控制逻辑。
- **FR-003**: 系统 MUST 支持发现 Java 工具定义及显式工具回调，校验名称、描述、输入约束和冲突来源；同一注册对象重复发现不得导致重复执行，冲突不得静默覆盖。
- **FR-004**: 系统 MUST 继续按 Agent 明确声明形成最小工具集合；未知本地工具在模型调用和轮次创建前失败；运行期未授权调用零真实执行，返回安全错误供模型继续。
- **FR-005**: 每个新增工具 MUST 在执行前检查授权、租约及预算并确认审计，完成后更新同身份记录；输入、结果、事件、历史及错误均受既有脱敏与长度限制。
- **FR-006**: 所有工具 MUST 共享本轮截止时间和调用次数；默认继续使用模型 10 次、单工具 10 次、总工具 30 次、整轮 30 秒、普通结果 10000 字符，实际重试也消耗预算；新分片或重连不能重置当前调用预算。
- **FR-007**: 工具 MUST 支持声明幂等性、超时和结果长度；未声明幂等性的插件及远程工具默认不自动重试。`write_file`、`edit_file`、`shell`、`http_post`、`ask_user` MUST NOT 自动重跑；其他工具仅沿用 004“幂等且明确未开始的瞬时失败最多重试一次”的条件。
- **FR-008**: 系统 MUST 对普通工具错误提供安全可继续结果；审计失败、租约丢失和整轮超时结束本轮；动作或审计完成状态不明时明确说明不确定性并禁止重放。

- **FR-009**: 文件工具 MUST 使用部署者配置的工作根目录及读、写允许范围，默认无文件权限；相对路径相对于工作根解析，绝对路径也必须经过同等校验。
- **FR-010**: 文件工具 MUST 校验最终真实目标与路径边界，拒绝路径穿越和越界软链接；写入尚不存在的文件时也检查真实父目录。目标在校验与提交间变化或不能确认仍获准时必须拒绝。
- **FR-011**: `read_file` MUST 只读取大小限制内的普通 UTF-8 文本；过大或不支持的文件返回安全错误，不读取无上限正文，返回文本仍经过统一治理。
- **FR-012**: `write_file` MUST 支持创建及显式允许后的覆盖；默认拒绝覆盖已有目标；父目录不存在时安全失败，不隐含创建目录。内容编码为 UTF-8，提交前失败不得损坏原文件或留下半成品目标。
- **FR-013**: `list_dir` MUST 只列出授权目录的直接子项，按名称稳定排序，返回名称、类型与受限路径，达到条数上限时明确表示还有未返回项。
- **FR-014**: 文件读取与写入 MUST 在实际动作前分别匹配所需权限，不能由可读取推导出可写入，也不能由可写入推导出可读取；现有内容编辑必须同时取得读写权限。
- **FR-015**: 所有文件操作 MUST 在文件字节上限与本轮时间内执行；搜索单文件读取、扫描范围及返回条数均须有独立上限，超限不冒充完整结果。

- **FR-016**: `shell` MUST 仅运行部署者明确授权的可执行文件，参数以独立数组值传递，不隐含启用命令行解释、管道、重定向或命令替换。
- **FR-017**: `shell` MUST 校验真实可执行文件及获准工作目录，默认拒绝命令启动；不得因 PATH 或用户输入的环境设置而调用另一未授权程序。
- **FR-018**: `shell` MUST 返回退出码、受限的标准输出和错误输出及截断标记；输出超过收集上限时停止保留超额输出，但继续排空或安全终止，不能因输出管道填满无限阻塞。
- **FR-019**: `shell` MUST 在超时、取消或租约失效时停止等待，并在清理窗口内尝试终止本次可识别的进程树；未确认清理成功时明确报告，不伪称已停止全部动作。文档须说明直接命令授权不隔离获准程序内部行为。

- **FR-020**: 系统 MUST 支持配置 MCP 服务及其所需连接信息，覆盖本地进程、SSE 和 Streamable HTTP 三种接入方式；配置凭证使用环境引用，配置错误提供安全来源提示。
- **FR-021**: MCP 初始化和发现 MUST 按服务独立受限并且不阻塞本地能力就绪；默认初始化预算 10 秒，单次调用预算默认 30 秒且不能超过本轮剩余预算。
- **FR-022**: 系统 MUST 为服务间同名工具提供稳定的来源区分名称，并对最终合并目录再次执行重名校验；本地与远程同名不得产生来源混淆。
- **FR-023**: Agent MUST 同时显式声明 MCP 服务及其公开工具名才获得远程工具权限；服务引用不隐含授权其全部当前或未来工具，未知服务引用在加载期失败。
- **FR-024**: 已配置但暂时不可用的 MCP 来源 MUST 允许 Agent 加载并保留不可用状态；只对可明确归属该来源的声明延迟具体工具存在性校验，不放行未知本地名或其他来源；恢复后发现确实不存在的工具应在后续轮次开始前报配置错误。
- **FR-025**: 失联来源 MUST 后台有界退避重连，退避上限为 5 分钟；恢复后重新发现并校验工具，后续轮次使用更新后的目录，当前轮次保持原名称、来源和授权快照，失效来源返回安全不可用错误。
- **FR-026**: MCP 发现连接与调用 MUST 遵循部署者对远程地址或本地启动程序的授权；每次发现、重连不得绕过授权，远程服务内部动作不得被宣称受本地文件或命令白名单隔离。
- **FR-027**: 远程调用 MUST 只转发工具业务参数和明确允许的元数据；默认不转发内部会话/轮次对象、租约、工作区和预算对象，也不能把它们暴露为模型参数；失败记录不得泄漏凭证和敏感地址。
- **FR-028**: 系统 MUST 在调用取消和应用退出时有界关闭等待、连接及其负责启动的服务进程；远程结果不明不得自动重放；单服务失败不得中断其他来源已获准的调用。

- **FR-029**: `http_post` MUST 支持向授权的 HTTP/HTTPS 地址提交 UTF-8 文本或 JSON 文本并指定内容类型；不得向模型开放任意认证配置或内部上下文。
- **FR-030**: POST MUST 在网络动作前校验目标、请求正文上限及预算；沿用 HTTP 默认空域名名单、拒绝用户信息和非法协议。默认请求、响应正文上限分别为 1 MiB。
- **FR-031**: POST MUST 不自动跟随重定向，也不得自动重发；非成功状态、网络错误和超大响应返回安全错误，不附响应正文或原始敏感异常；连接、响应和正文读取使用同一剩余预算。
- **FR-032**: POST 若在可能已发送后超时、取消或完成状态未知，MUST 明确提示提交可能生效；不得将此类状态当作确定未发送，实际请求数须可验收。

- **FR-033**: `edit_file` MUST 仅在非空旧文本恰好匹配一次且目标未被并发改变时替换，保留其他内容；无匹配、多匹配、超限和提交前失败时原文件不变。
- **FR-034**: `grep` MUST 在授权目录中按字面文本搜索，返回相对路径、行号和受限匹配内容；`glob` MUST 按文件名模式返回授权目录内匹配路径。两者排序稳定，不跟随目录软链接递归扩大扫描范围。
- **FR-035**: 文件搜索 MUST 有返回、扫描条目、单文件大小和时间上限；跳过不支持、过大或无法读取的条目时返回安全的原因计数，扫描中断或达到上限时明确表示不完整；越界条目不返回内容或敏感路径。

- **FR-036**: `ask_user` MUST 通过当前入口交互能力向当前用户提问，不直接假定本地控制台可用；至少提供可交互命令行和不支持交互两种行为。
- **FR-037**: 不支持交互的入口 MUST 不等待用户输入；支持交互时问题与回答属于原轮次，输入结束、并发占用及回答超限都须得到明确结果。
- **FR-038**: 提问等待 MUST 受本轮剩余预算、取消和租约约束；结束后不得把迟到输入交付给已结束轮次或误交付其他轮次。问题和答案沿用敏感信息与长度治理。

- **FR-039**: `web_search` MUST 通过可配置的搜索提供者获取信息，至少交付一个实际可配置的提供者实现，而非仅有空接口或固定假结果；未配置时明确报告不可用。
- **FR-040**: 搜索 MUST 校验查询长度、结果条数、服务地址授权、响应大小和剩余预算；返回标题、链接、摘要，不默认抓取结果页面，返回链接不自动扩大白名单。
- **FR-041**: 搜索 MUST 区分完整无结果、被截断的结果、服务失败与未配置；不能伪造结果，不能向用户、模型、日志或审计暴露服务凭证。

- **FR-042**: 系统 MUST 同期提供 `AgentOS tool list` 命令和只读工具列表服务查询，均展示全局工具名称、描述、来源、可用状态，并提供指定 Agent 的授权视图；该服务查询独立于完整会话服务交付。
- **FR-043**: 工具查询 MUST 展示已配置但未发现工具的不可用来源；两个入口在同一目录快照下的内容一致，不泄露凭证、环境值或含密钥的连接地址。
- **FR-044**: 工具查询 MUST 不执行工具、不调用模型、不创建用户会话或轮次；不得把全局可查等同于该 Agent 已获执行授权。

- **FR-045**: 每项新增能力 MUST 具备正常、未授权、参数错误、资源上限、超时/取消和审计路径的验收证据；全部来源均要验证模型可见集合、调用标识关联和下一轮结果回填。
- **FR-046**: 默认验收 MUST 使用临时工作区、本地服务与独立数据库，覆盖三种 MCP 连接方式；真实模型、搜索服务及外部 MCP 联调独立显式启用，缺少依赖时记录 NOT_RUN，不将替身成功冒充真实服务成功。
- **FR-047**: 实施 MUST 保留 004 的正常完成、受控重试、零越权执行、审计未确认、共享预算、脱敏及恢复验收；新增工具不能降低既有门禁或以跳过数据库测试换取通过。
- **FR-048**: 每个故事 MUST 提供可重放演示及配置说明，并记录实际动作次数、审计状态、取消清理结果和 PASS/FAIL/NOT_RUN；天气、科技和 GitHub 信息汇总演示仅返回当前入口，不以未交付的记忆、通知或定时能力作为前置条件。

### Key Entities *(include if feature involves data)*

- **工具条目**：名称、说明、输入约束、来源、治理属性及可用状态；包含本地和远程两种来源。
- **Agent 工具授权**：允许的工具名称及远程服务引用；决定模型可见和实际可执行集合。
- **文件访问范围**：工作根目录、读写允许位置、最终真实目标和文件/扫描上限。
- **命令执行授权**：允许的真实程序、工作目录及执行/输出限制。
- **远程工具来源**：服务名称、连接方式、凭证引用、可用状态、重连状态及已发现工具。
- **工具目录快照**：某一轮次或查询采用的稳定名称、来源、定义和授权版本。
- **工具调用及审计**：沿用既有调用身份、状态、尝试次数、受限结果和持久化确认信息。
- **交互请求**：原轮次的问题、回答接收状态、截止时间及结束原因。
- **搜索提供者及结果**：配置的服务、可用状态，以及受限的标题、链接和摘要。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 新增 10 个工具均能分别完成至少一条正常路径和一条拒绝/失败路径演示；文档列为可用的工具与运行时目录一致率为 100%。
- **SC-002**: 授权矩阵中每个未授权文件目标、程序、网络地址和远程工具用例的实际越权动作数为 0；被拒绝的文件写入和编辑用例中，原文件内容保持率为 100%。
- **SC-003**: 同一测试插件加入后无需修改 Agent 的思考循环，授权 Agent 可调用，未授权 Agent 零执行；重名与定义错误用例全部在实际调用前被识别。
- **SC-004**: 文件创建、覆盖和唯一匹配编辑的正常样本读回与预期完全一致；上限、无匹配、多匹配、并发变化及提交前故障样本均不造成部分写入。
- **SC-005**: 命令参数含特殊字符的样本均不产生额外命令；未授权样本启动数为 0。超时与取消样本各重复 20 次，正常可清理的受控进程树均在截止时间加 1 秒内确认退出；异常未确认清理须明确呈现。
- **SC-006**: 三种远程连接方式各有发现、调用和关闭的通过证据；一个来源失联时其他来源与本地工具成功率为 100%。注入一个永不响应的来源，相比无该来源的本地就绪耗时增加不超过 1 秒。
- **SC-007**: 恢复验收中，来源恢复后的下一次计划重连须成功更新后续轮次可见目录；当前轮次的原来源关联保持率为 100%，未声明的新工具可执行数为 0。
- **SC-008**: 已发送后故障和重定向的提交样本，各原目标请求数最多 1 次，重定向下一跳请求数为 0；所有不确定完成均明确提示可能生效。
- **SC-009**: 每种文件搜索边界用例都能区分完整无结果、结果截断与扫描不完整；越界文件内容泄漏数为 0。
- **SC-010**: 可交互、无人值守、输入结束及取消四类提问场景全部有确定结果；无人值守替身 20 次调用均在 1 秒内返回不支持，迟到回答被错误交付次数为 0。
- **SC-011**: 搜索验收的有结果、空结果、未配置、拒绝、服务失败与超限六类结果全部正确区分，返回条数不超过所配上限，前置拒绝导致的网络请求数为 0。
- **SC-012**: 命令行和只读服务入口在同一快照下展示的工具名称、来源、状态和 Agent 授权集合完全一致；两类查询引发的模型、工具、会话和轮次新增数均为 0。
- **SC-013**: 所有新增来源的验收调用均能按原调用标识关联到审计和下一轮结果；安全抽样中用户结果、历史、日志、审计及目录查询的凭证和内部敏感上下文泄漏数为 0。
- **SC-014**: 慢正文、远程等待、持续命令输出、用户交互等待和持续搜索响应五类场景各重复 20 次，每类 p95 在配置预算加 1 秒内结束；既有核心验收全部通过，真实依赖未运行项单独标为 NOT_RUN。

## Assumptions

- 本规格建立在 004 已验证的授权、执行、审计和限次语义上；继承其质量门和隔离验证约束，不重新定义完整会话或 Provider 能力。
- 部署者可维护应用配置及其环境配置文件；文件、命令与网络允许范围由部署者配置，默认均拒绝。Agent 仍主要声明工具集合，不在本期增加复杂的每 Agent 沙箱策略覆盖。
- 默认工作根目录为当前 AgentOS 工作区；授权路径以部署配置为准，软链接到公共参考资料也必须取得最终目标授权。没有授权的工作区不因“位于本机”而自动开放。
- 新的默认资源边界如下；部署者可收紧这些上限。所有边界均额外受到共享截止时间及统一结果上限约束。

| 资源 | 默认边界 |
|---|---|
| 单文件读取、写入、编辑内容 | 1 MiB；普通 UTF-8 文本 |
| 单次目录列表、文件搜索结果 | 200 项 |
| 单次文件搜索扫描 | 最多 1000 个目录项，单文件最多 1 MiB；不递归跟随目录软链接 |
| 命令收集输出 | 标准输出和错误输出合计 64 KiB，保留截断状态 |
| 新工具单次等待 | 默认 30 秒，取其与本轮剩余预算的较小值 |
| MCP 初始化 | 每来源 10 秒；不阻塞本地能力就绪 |
| MCP 重连 | 初次延迟 1 秒，失败后倍增，最多 5 分钟；不延长正在执行的调用 |
| POST 请求与响应正文 | 分别最多 1 MiB；不跟随跳转，不自动重发 |
| 提问与回答 | 各最多 4000 字符；不支持交互时立即失败 |
| 搜索查询 | 最多 1000 字符，最多返回 10 条；响应正文最多 1 MiB |
| 取消/关闭清理验收窗口 | 配置截止时间后最多 1 秒；无法确认时明确记录失败或不确定 |

- 文件搜索采用字面文本和文件名模式，不扩展为任意复杂正则表达式或完整代码索引服务。
- 本期命令与本地 MCP 进程均在可信宿主机权限下运行；解释器只有被管理员明确允许才可启动，不提供不可信代码或多租户隔离承诺。
- 至少一种搜索服务的提供者选型在规划阶段确定，交付必须包含真实可配置实现与本地替身验收；测试凭证、服务地址和对外联调可用性单独记录。
- 工具列表服务属于本期最小只读查询，不据此提前实现完整 Web Service；CLI 与该入口应共享同一目录及状态事实。
- 每个故事的默认演示使用隔离数据和受控替身；真实模型及外部服务联调只显式开启，不读取个人凭证文件，不向他人发送消息或通知。
- 完成真实模型验收依赖可用测试连接；未提供时整体实现报告可以说明本地验收完成，但不得宣布真实外部兼容性通过。
